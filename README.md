# Продюсер — трекер запусков

Адаптивная платформа (телефон + ноутбук) для продюсера: эксперты, касания, созвоны, возражения, задачи и аналитика.
Построена по материалам обучения: «Запуск бизнеса и продюсирование», «Холодное касание», «Созвон с экспертом», «Работа с возражениями».

Без сервера и сборки: чистый HTML/CSS/JS. Данные хранятся в браузере, есть резервная копия (JSON) и выгрузка в CSV.

## Публикация на GitHub Pages
1. Влей ветку в `main` (или `master`).
2. **Settings → Pages → Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует сайт: `https://<логин>.github.io/platform_prod/`.
4. На телефоне: открыть ссылку → «Добавить на главный экран» (работает офлайн).

Локально: `python3 -m http.server` и открыть http://localhost:8000.

## Что внутри
| Раздел | Что делает |
|---|---|
| Сегодня | Нормы 4/день · 20/неделю · 120/месяц, темп, список действий на сегодня, «пора отпускать» |
| Эксперты | Доска (drag-and-drop) и список: 11 этапов пути, критерии отбора, «красные флаги», история, автоследующее действие |
| Касание | Быстрая запись; авто-напоминание через 3 дня, максимум 3 касания, затем пауза на 2–3 месяца |
| Созвон | Таймер 15 мин по шагам, подсказки «делай / не делай», заметки, итог с обязательным следующим шагом |
| Скрипты | Конструктор первого сообщения с проверкой правил, ответы, дожимы, 5 возражений, признаки «сольётся» |
| Задачи | Домашние задания и дела, привязка к эксперту, сроки |
| Аналитика | Воронка касания → ответы → созвоны → работа, диагностика по правилам обучения, каналы, отчёт наставнику, калькулятор 40% с прибыли |
| Путь | Лестница ролей, этапы, условия (0% первый месяц, 40% со второго) |

## Ограничения
Данные не синхронизируются между устройствами — переноси через «Резервная копию» в настройках.
Для общей панели наставника понадобится бэкенд (например Supabase/Firebase) — архитектура это допускает: вся логика в `js/core.js`.
